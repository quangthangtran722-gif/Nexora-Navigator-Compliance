# Bảng thuật ngữ (từ nexora-wording-v1.md, mục 2)

Mỗi khái niệm chỉ có một tên, dùng giống nhau ở mọi trang. Cột trái là từ nội bộ / từ cũ — **không xuất hiện trên giao diện**.

| Đang dùng | Đổi thành | Ghi chú |
| :-- | :-- | :-- |
| Diagnostic | **Nghĩa vụ** | Một việc doanh nghiệp phải tuân thủ theo một điều luật |
| Checklist | **Việc cần làm** | Các đầu mục bên trong một nghĩa vụ |
| Duyệt diagnostic | **Xác nhận nghĩa vụ** | Tên trang và mục menu |
| Duyệt (khách hàng) | **Xác nhận** | Khách xác nhận nghĩa vụ có thật sự liên quan tới công ty |
| Duyệt & giao | **Xác nhận & giao việc** | Nút chính |
| Từ chối (khách hàng) | **Không liên quan** | Nút phụ |
| Trạng thái: Chờ duyệt | **Chờ xác nhận** | |
| Trạng thái: Đã duyệt | **Đã giao việc** | |
| Trạng thái: Từ chối | **Không liên quan** | |
| Áp dụng | **Đang áp dụng** | |
| Sắp áp dụng | **Sắp có hiệu lực** | |
| Chưa đủ thông tin | **Cần bổ sung thông tin** | |
| Không áp dụng | Không áp dụng | Giữ nguyên |
| Hỏi bổ sung | **Cần bổ sung thông tin** | Trùng nghĩa với trạng thái trên, dùng một tên |
| Hộp thư phòng ban | **Thông báo** | Tên trang và mục menu |
| Onboarding | **Hồ sơ doanh nghiệp** | Mục menu; tên trang khi chưa xong: "Thiết lập hồ sơ doanh nghiệp" |
| Người đầu mối | **Người phụ trách tuân thủ** | |
| Khách hàng (nhãn vai trò, breadcrumb phía khách) | Bỏ | Khách không tự gọi mình là "khách hàng" |

| Chunk | **Phần** | "Phần 1 · Điều 1–3" |
| Kho entity | **Thư viện pháp lý** | |
| Pipeline / Nhật ký pipeline | **Lịch sử xử lý** | |
| Rule engine | Không nhắc tên | Nói "cách xác định nghĩa vụ áp dụng" khi cần giải thích |
| Điều kiện máy đọc | **Điều kiện áp dụng** | |
| AI mô tả | **Tóm tắt** | |
| Quét lại | **Cập nhật** | "Cập nhật tất cả", "Cập nhật khách hàng này" |
| Yêu cầu AI viết checklist / AI viết N checklist | **Tạo việc cần làm** | |

Bổ sung đã dùng trong app (lib/copy.ts):

| Khái niệm | Tên dùng |
| :-- | :-- |
| Relationship giữa các mục trích xuất | **Liên kết** |
| Kết quả trích xuất | "N mục trích xuất · N liên kết · N cảnh báo" |
| Ngoại lệ được nói về tự động | Một dòng duy nhất trên hàng nút xác nhận: "Nội dung gợi ý được tạo tự động. Vui lòng kiểm tra trước khi xác nhận." |
| Mục kỹ thuật được phép dùng thuật ngữ nội bộ | "Chi tiết kỹ thuật" ở trang Lịch sử xử lý |
